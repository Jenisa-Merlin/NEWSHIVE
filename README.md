/start, /help, /settings - Shows welcome message and available commands
/news or simply sending "News [keyword]" - Get latest news about a specified topic
/semantic [query] - Search news semantically based on a query
/news_by_date [YYYY-MM-DD] [keyword] - Fetch news for a specific date and keyword
/news_with_media [keyword] - Same as regular news but focuses on results with media
/media [keyword] - Shows a media gallery (images/videos) for a specific news topic

Options and Configuration

/options or sending "options" - Shows configuration options
/domains - Shows currently used domains/sources for news
/timeframe - Shows and lets you modify how many days back to search for news

Google Sheets Integration

/save_to_sheets [keyword] - Save news articles to Google Sheets
/export_daily - Export today's news for all configured topics
